# dsh-files-explorer

Local DeepSeek Harness client plugin. It does not replace the shipped Files
tab. It wraps the right sidebar so a file opened from the tree lands in a
second pane, and it adds a VS Code-style right-click menu on tree rows.

Menu items:

- Open
- Open in New Tab (`.html`, `.htm`, `.xhtml`)
- Copy Path
- Copy Relative Path
- Copy Name
- Reveal in Finder
- Open with Default App / Open in Finder
